# 第2回講義メモ

## 関数定義

### 関数定義の例1
- **2個の数値型の引数**を受け取って，**真偽値型を戻り値**とする関数```comp```のシグネチャ (=関数の基本的な情報を定義する部分)
```
function comp(a: number, b: number ): boolean { ... }
```

### 関数定義の例2
- **1個の文字列型の引数**を受け取って，**戻り値を持たない**関数```printWord```<-**キャメルケース表記**
- 戻り値がないことは```void```で表現する
```
function printWord(word: string): void { ... }
```

### 関数定義の例3
- **引数を受け取らず**，**数値型を戻り値**とする関数```dice```
- 引数がないことを```void```で表現することはできない
```
function dice(): number { ... }
```

## 関数を別ファイルに分離する
- ```prac05.ts```を参照
```
import { date2str } from "./utils/date2str.js"; // 関数date2strをインポート

const deadline: Date = new Date(2025, 9, 2, 14, 15);
const createdAt: Date = new Date(2025, 8, 25, 9, 45);

const str = `期限 ${date2str(deadline)} (登録日 ${date2str(createdAt)})`;
console.log(str);
```
note.<br>
ここで注意したいのは```from "./utils/date2str.ts";```ではなく```from "./utils/date2str.js";```のように記述している点である．<br>
これは，ビルド時に```date2str.ts```から```date2str.js```に変換されることを前提としているためである．

##  日時を整形する関数をテストする
- ```date2str.ts```, ```date2str.test.ts```を参照
- ```date2str```は，実行環境のタイムゾーンに合わせて日時を文字列にする．例えば，日本時間の環境では日本時間として，UTCの環境ではUTCとして表示する．**表示を常に日本時間にする関数ではない**ことに注意．
- 今回のテストでは，```new Date(2026, 0, 3, 4, 5)```のように，日時を実行環境のローカル時刻として指定している．そのDateオブジェクトを，同じ環境の```date2str```で文字列にするので，作成時に指定した「1月3日04:05」が```"2026/01/03 04:05"```として出力されることを確認している．<br>
-> **ローカル時刻として作った日時を、同じローカル時刻として正しく文字列化できるか**をテストしている．
