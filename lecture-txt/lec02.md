# 関数定義

## 関数定義の例1
- **2個の数値型の引数**を受け取って，**真偽値型を戻り値**とする関数```comp```のシグネチャ (=関数の基本的な情報を定義する部分)
```
function comp(a: number, b: number ): boolean { ... }
```

## 関数定義の例2
- **1個の文字列型の引数**を受け取って，**戻り値を持たない**関数```printWord```<-**キャメルケース表記**
- 戻り値がないことは```void```で表現する
```
function printWord(word: string): void { ... }
```

## 関数定義の例3
- **引数を受け取らず**，**数値型を戻り値**とする関数```dice```
- 引数がないことを```void```で表現することはできない
```
function dice(): number { ... }
```
